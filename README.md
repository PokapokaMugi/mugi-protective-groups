# 保護基リファレンス

Greene’s Protective Groups in Organic Synthesis, 4th edition の索引に基づく保護基検索ツール。

- 官能基別の一般情報、導入・脱保護、化学耐性、pH区分、文献の確認記録
- 1,279索引項目、うち1,078項目・5,248件の反応記載を個別整理
- 原書画像・条件全文・全文検索は手元のGreene第4版PDF（1,108ページ）をブラウザー内で読み込んで使用
- PDFや書籍本文は公開リポジトリに含めず、選択したPDFをサーバーへ送信しません
- 任意でIndexedDBにPDFを保存でき、画面上のボタンで解除できます

全一次文献・SIの検証は未完了です。条件の適用範囲と原書画像、確認範囲別の文献記録を確認してください。耐性グラフは原書の離散区分に基づく参考値で、連続した実測pH安定域ではありません。
